# 管理后台使用指南

面向管理员与运营人员。完整可搜索的指南已内置在后台，登录后从侧边栏「使用指南」进入，或点击工作台「查看完整使用指南」。

## 日常发布流程

1. 使用管理员分配的后台账号登录，进入需要维护的模块。后台账号与小程序微信登录账号不同。
2. 编辑文字，上传图片或视频。等待文件显示「已校验」后，点击「保存草稿」。
3. 检查预览，确认无误后点击「发布」「发布到首页」或「上架」。
4. 看到成功提示后，重新进入或刷新小程序对应页面，核对实际显示。

保存草稿不会影响线上内容。右侧小程序预览展示当前编辑内容，草稿预览展示已保存内容，均不会自动发布。离开页面前先保存，避免丢失未保存的修改。

## 各模块怎么维护

| 模块 | 维护内容与注意事项 |
| --- | --- |
| 首页头图 | 上传一张包含品牌文字和画面的完整图片，不填写额外标题、副标题或焦点。图片按原始比例展示，保存后再发布到首页。 |
| 首页宣传视频 | 填写视频标题，分别上传视频及封面，保存后播放预览并发布。同一时间首页只展示一条，发布新视频会替换旧视频。 |
| 公司介绍 | 基础信息维护首页标题、简介、封面；详情内容按板块填写标题、文字，可选插图。详情插图合计最多 10 张。可展开、收起并调整板块与插图顺序。 |
| 景区管理 | 维护名称、简介、封面、详情、开放状态与展示顺序。导航选填；地图中点选地点后还需确认，随后保存并发布。「暂停开放」不等于下架。 |
| 会员福利 | 填写名称、简介，上传最多 10 张产品图片，并点选其中一张作为列表封面。详情顶部相册展示全部产品图片；详情文字与图片选填，没有详情时不展示详情图文区域。 |
| 产品分类 | 在会员福利管理的「产品分类设置」中维护分类。保存后还需启用；修改已启用分类后也要发布修改。停用分类不等于下架所属产品。 |
| 收益板块管理 | 维护核心收益来源、合作价值总结的名称、说明与顺序。收益图标自动匹配，也可选择内置图标；合作价值图标按顺序生成。两类内容发布前都至少需要一项。 |

展示顺序数字越小越靠前。收益条目和合作价值条目没有详情页；分公司方案、会员体系当前没有编辑功能，小程序切换后中间区域显示「敬请期待」，下方仍保留合作价值总结。

图片支持 JPEG、PNG、WebP，单张最大 10 MB；宣传视频支持 MP4，最大 200 MB。产品「产品图片」相册与「详情内容」插图是两个独立用途，不能混淆。

## 账号与权限

- 运营人员可以编辑、上传、发布内容；管理员还可以查询注册用户和管理后台人员。
- 管理员可创建人员账号、调整角色、重置密码、停用账号。初始密码至少 12 位，包含大写字母、小写字母和数字。
- 重置密码、调整角色或状态会使相关账号的原有登录会话失效。
- 注册用户页面用于查询，只展示脱敏手机号，不提供用户资料编辑、充值、会员升级或订单处理功能。
- 结束操作后点击后台右上角「退出登录」。不要共享账号、公开密码或随意转发用户信息。

## 常见问题 QA

### 保存了，为什么小程序还是旧内容？

保存只更新草稿，还需要发布或上架。确认成功后重新加载小程序页面。仅修改现有模块的内容不需要重新提审小程序；新功能和界面变动由开发人员处理。

### 发布按钮为什么是灰色的？

检查必填项、发布条件和上传校验状态。存在未保存修改时，先保存草稿；没有已保存草稿时也不能发布。

### 不配地图能发布景区吗？产品详情可以不填吗？

都可以。景区导航位置选填；产品详情图文选填。产品上架仍需要名称、简短介绍和列表封面。

### 产品上传了两张图片，列表为什么只看到一张？

列表只展示选定封面，完整相册在产品详情顶部左右滑动查看。相册图片需在「产品图片」上传，仅上传到「详情内容」不会成为相册图片。

### 上传失败怎么办？

核对格式、大小和网络，等待上传及校验完成。仍失败时记录错误提示、时间与所在模块，联系开发人员；不要连续重复点击。

### 内容被别人修改，或者出现版本冲突怎么办？

先复制留存未保存的文字，刷新读取最新内容，与另一位操作人员确认后重新编辑。不要反复提交旧页面。

### 下架和删除有什么区别？

下架暂时隐藏内容，可以重新编辑、发布。删除不可在后台撤销。临时隐藏优先下架；确需删除已发布内容时先下架，再确认删除。

### 登录失效或忘记密码怎么办？

登录失效时重新登录；仍失败请联系管理员确认账号状态。忘记后台密码由管理员在「后台人员」重置。运营人员看不到注册用户和后台人员入口是正常权限限制。

### 「敬请期待」是权限不足吗？

不是。对应功能尚未开放，没有编辑表单或启用开关，需要开发人员完成新功能后才可使用。

### 需要帮助时提供什么？

提供模块名称、执行的操作、问题发生时间、错误截图和追踪号。追踪号供开发人员查询日志，不是密码。截图前遮住密码和不必要的用户信息，不要提供密码、验证码或密钥。
