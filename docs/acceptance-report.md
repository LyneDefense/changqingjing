## 安全与依赖检查

| 检查项 | 结果 |
| --- | --- |
| 后台认证／CSRF | Cookie 会话、CSRF 写保护、停用校验和 30 分钟闲置／12 小时绝对期限已有自动测试。 |
| 小程序认证边界 | Bearer 与后台 Cookie 互不接受；产品和本人资料接口要求登录。 |
| CORS | 后端采用同域访问且不返回跨域允许头；COS CORS 已由用户配置，部署时仍需按真实后台 Origin 复核。 |
| 上传临时凭证 | 15 分钟、单个随机 Object Key、仅 `PutObject`；服务端再校验大小、类型、ETag 和文件签名。 |
| 限流 | 微信登录、后台登录、上传凭证和景区浏览上报均有每 IP 限流；并发原子性测试通过。后台失败登录另有账号/IP 联合锁定。 |
| 安全响应头 | CSP、Referrer-Policy、Permissions-Policy、nosniff 和拒绝 iframe 已测试。 |
| 日志脱敏 | 日志测试确认不写入密码、手机号、微信 code、Authorization 或请求体。 |
| 秘密扫描 | `scripts/check-secrets.sh` 通过；只扫描 Git 跟踪文件，不读取本地秘密文件。 |
| 前端依赖 | `pnpm audit --prod --audit-level high` 两端均为高危／严重 0。 |
| 已评估中危 | 后台 COS SDK 的 XMLBuilder comment/CDATA 注入不在当前调用路径；小程序 esbuild 告警仅影响不对外监听的本地开发服务。等待上游兼容升级，不以跨大版本覆盖冒运行风险。 |
| OpenAPI | `contracts/openapi.json` 从真实 Controller 生成；两端生成类型、关键 DTO 和路由由 TypeScript 构建检查。默认环境关闭 OpenAPI 端点。 |

## 发布前仍需完成

- iOS 与 Android：真实手机号同意／拒绝／取消／恢复登录、两个登录入口和产品直达链接。
- iOS 与 Android：景区导航目的地、长页面、安全区域和弱网／断网重试。
- Android：真实 MP4 播放；iOS 播放已由用户确认。
- 用最终视频、产品多图、公司长文和长地址验证 10 MiB 图片、200 MiB MP4 的实际容量边界。
- 在测试服务器上复核 Secure Cookie、HTTPS、COS 精确 CORS、STS 越权写入被拒绝和反向代理后的真实客户端 IP 限流。

自动化验收统一入口为 `JAVA_HOME=/path/to/jdk-18 ./scripts/verify-release.sh`；小程序端到端步骤要求本机已安装并登录微信开发者工具。
