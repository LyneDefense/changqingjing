# 常清净文旅投

本仓库包含三个独立工程：

- `backend`：JDK 18 + Spring Boot 3.2.12，包含小程序 API 与管理后台 API。
- `admin-web`：React + TypeScript + Vite 管理后台。
- `miniprogram`：Taro + React + TypeScript 微信小程序。

产品、技术和实现节点文档见 [docs/README.md](docs/README.md)。

三个工程已经完成初始化，当前进入 [N2：PostgreSQL 与后端公共基础](docs/implementation-roadmap.md)。
